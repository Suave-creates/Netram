# VC S19003 Labeller Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a first local browser labeller for `VC S19003` with editable shape labels, grouping, deletion, pan/zoom, and file-backed memory.

**Architecture:** A Python standard-library server serves a dependency-free HTML/CSS/JS frontend and JSON memory endpoints. The PDF is rendered once to a PNG asset, while editable labels/groups persist to JSON memory files. Pure frontend state functions are isolated for Node tests.

**Tech Stack:** Python 3.13 standard library, Node 24 built-in test runner, browser HTML/CSS/JavaScript, Poppler `pdftoppm` for PDF preview rendering.

## Global Constraints

- Only `VC S19003` is supported in this pass.
- `files_PDF/VC S19003.pdf` and `files_CAD/VC S19003.dwg` remain unmodified source files.
- Each visible drawing shape is labelled separately; groups represent physical components.
- Saved memory lives at `eyewear_labeller/memory/VC S19003.labels.json`.
- Physics/maths memory lives at `eyewear_labeller/memory/eyewear-physics-maths.md`.
- No network package install is required.
- This folder is not a git repository, so implementation steps skip commits.

import tempfile
import unittest
from pathlib import Path

from eyewear_labeller import server


class MemoryApiTest(unittest.TestCase):
    def setUp(self):
        self.tmp = tempfile.TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.original_memory_dir = server.MEMORY_DIR
        server.MEMORY_DIR = Path(self.tmp.name)

    def tearDown(self):
        server.MEMORY_DIR = self.original_memory_dir

    def test_save_and_load_memory_round_trip(self):
        payload = {
            "modelId": "VC S19003",
            "labels": [
                {
                    "id": "label-1",
                    "type": "rect",
                    "component": "rim",
                    "view": "front",
                    "points": [{"x": 10, "y": 20}, {"x": 30, "y": 40}],
                    "groupId": None,
                    "notes": "left front rim seed",
                }
            ],
            "groups": [],
            "updatedAt": "2026-06-20T00:00:00.000Z",
        }

        saved = server.save_memory("VC S19003", payload)
        loaded = server.load_memory("VC S19003")

        self.assertEqual(saved["modelId"], "VC S19003")
        self.assertEqual(loaded["labels"][0]["component"], "rim")
        self.assertTrue((Path(self.tmp.name) / "VC S19003.labels.json").exists())

    def test_rejects_memory_for_wrong_model(self):
        with self.assertRaises(ValueError):
            server.save_memory("VC S19003", {"modelId": "VC S19004", "labels": [], "groups": []})

    def test_rejects_label_without_points(self):
        with self.assertRaises(ValueError):
            server.save_memory(
                "VC S19003",
                {"modelId": "VC S19003", "labels": [{"id": "bad"}], "groups": []},
            )

```javascript
import assert from 'node:assert/strict';
import test from 'node:test';

import {
  createInitialState,
  deleteSelection,
  groupSelection,
  serializeState,
  toggleSelection,
} from '../static/label-state.mjs';

const memory = {
  modelId: 'VC S19003',
  labels: [
    { id: 'a', type: 'rect', component: 'rim', view: 'front', points: [{ x: 1, y: 1 }, { x: 2, y: 2 }], groupId: null, notes: '' },
    { id: 'b', type: 'rect', component: 'rim', view: 'top', points: [{ x: 3, y: 3 }, { x: 4, y: 4 }], groupId: null, notes: '' },
  ],
  groups: [],
};

test('shift-style additive selection keeps adjacent labels selected', () => {
  let state = createInitialState(memory);
  state = toggleSelection(state, 'a', false);
  state = toggleSelection(state, 'b', true);
  assert.deepEqual([...state.selectedLabelIds].sort(), ['a', 'b']);
});

test('groupSelection assigns selected labels to one physical component group', () => {
  let state = createInitialState(memory);
  state = toggleSelection(state, 'a', false);
  state = toggleSelection(state, 'b', true);
  state = groupSelection(state, 'rim', 'Left rim physical component');
  assert.equal(state.groups.length, 1);
  assert.equal(state.labels.find((label) => label.id === 'a').groupId, state.groups[0].id);
  assert.equal(state.labels.find((label) => label.id === 'b').groupId, state.groups[0].id);
});

test('deleteSelection removes selected labels and drops empty groups', () => {
  let state = createInitialState(memory);
  state = toggleSelection(state, 'a', false);
  state = toggleSelection(state, 'b', true);
  state = groupSelection(state, 'rim', 'Rim group');
  state = deleteSelection(state);
  assert.equal(state.labels.length, 0);
  assert.equal(state.groups.length, 0);
});

test('serializeState emits file-backed memory shape', () => {
  let state = createInitialState(memory);
  state = toggleSelection(state, 'a', false);
  const payload = serializeState(state, 'VC S19003');
  assert.equal(payload.modelId, 'VC S19003');
  assert.equal(payload.labels.length, 2);
  assert.match(payload.updatedAt, /^\\d{4}-\\d{2}-\\d{2}T/);
});
```
